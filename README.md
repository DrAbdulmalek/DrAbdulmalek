## Focus

I build practical, testable tools for Arabic and medical document processing, with an emphasis on:

- **OCR / handwriting recognition** — Arabic medical documents, preprocessing, routing and evaluation.
- **Human-in-the-loop training** — correction, provenance, datasets and reproducible exports.
- **Medical terminology & translation** — bilingual glossaries, translation tooling and knowledge bases.
- **Linux tooling** — safe maintenance and document-processing utilities.

## Engineering principles

**Evidence before claims · tests before merge · provenance over convenience · fail closed for security-sensitive paths · no silent OCR fallback.**

Projects are consolidated when they duplicate a stronger maintained implementation; archived repositories remain available as historical references.

## Selected ecosystem

- **OCR:** preprocessing, multi-engine routing, Arabic RTL handling, evaluation and HITL correction.
- **Data:** medical glossaries, bilingual dictionaries, ground-truth and training artifacts.
- **Translation:** reusable core + medical-domain workflows.
- **Operations:** Telegram/channel tooling and Linux maintenance.

For the current state of the portfolio, start with the repositories above rather than older archived demos.
